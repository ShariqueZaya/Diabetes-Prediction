🩺 Diabetes Prediction Using Machine Learning

A machine learning project that predicts whether a person may have diabetes based on diagnostic health measurements. The project uses Python and a trained machine learning model to generate predictions from user-provided input.

📌 Project Overview

Diabetes Prediction is a machine learning project designed to explore how patient health measurements can be used to predict the likelihood of diabetes.

The program accepts patient information, processes the input using a feature scaler, and uses a trained model to generate a prediction.

Disclaimer: This project is for educational purposes only and is not intended to diagnose diabetes or replace professional medical advice.

✨ Features

- Accepts patient health measurements as input.
- Processes input features using a scaler.
- Uses a machine learning model to generate predictions.
- Displays the prediction in the terminal.
- Uses a CSV dataset for model development.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

📂 Project Structure

Diabetes-Prediction/

⚙️ Installation

1. Clone the repository

git clone https://github.com/ShariqueZaya/Diabetes-Prediction.git

2. Navigate to the project directory

cd Diabetes-Prediction

3. Install dependencies

pip install -r requirements.txt

▶️ How to Run

Execute the Python script:

python diabetes_prediction.py

Enter the requested health measurements when prompted. The program will display its prediction in the terminal.

📊 Input Features

The program requests the following health measurements:

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI (Body Mass Index)
- Diabetes Pedigree Function
- Age

🎯 Project Objective

The objective is to apply machine learning techniques to a healthcare-related dataset and explore how predictive models can identify patterns in health measurements.
